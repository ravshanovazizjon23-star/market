# 🛍️ BLACK MARKET — Zamonaviy Internet Do'kon (Uzum Market uslubida)

Premium qora va to'q ko'k dizayndagi zamonaviy e-tijorat platformasi.

## 🚀 Asosiy imkoniyatlar:
- **Dizayn**: Chuqur qora (`#050814`) va to'q ko'k (`#0a1026`) gradient foni, nozik neon ko'k glow effektlari va zamonaviy glassmorphism.
- **Uzum Market uslubidagi funksiyalar**:
  - Shahar tanlash va 1 kunda bepul yetkazib berish info-paneli
  - Katta va qulay interaktiv qidiruv qatori (Live Search Suggestions)
  - Interaktiv Katalog menyusi va toifalar chiplari
  - Ommabop bannerlar slayderi (avtomatik almashuvchi promo bannerlar)
  - 4 ta asosiy afzalliklar bloki (Tezkor yetkazish, 0% muddatli to'lov, 100% original, oson qaytarish)
  - Mahsulot kartochkalarida: chegirma stikerlari, muddatli to'lov narxi (`... so'm/oyiga`), reyting va sharhlar soni, sevimlilar yurakchasi, tezkor ko'rish (Quick View)
  - Saralash: Arzon, Qimmat, Ommabop, Katta chegirma, Yuqori reyting
  - Mahsulot batafsil modal oynasi (rasmlar galereyasi, rang va o'lcham tanlash, to'liq xususiyatlar jadvali)
  - Savatcha (Cart Drawer): mahsulotlar miqdori boshqaruvi, `BLACK10` promokodi bilan qo'shimcha 10% chegirma, bepul yetkazish
  - Sevimlilar oynasi (Wishlist)
  - Buyurtmani to'liq rasmiylashtirish oynasi (Checkout modal) + Muvaffaqiyatli qabul qilingan chek kvitansiyasi
  - Foydalanuvchi tizimga kirish (SMS kod bilan) va buyurtmalar tarixi oynasi
  - Bildirishnomalar (Toast) tizimi
  - Ma'lumotlarni brauzerda saqlash (LocalStorage: savatcha va sevimlilar yangilanganda saqlanib qoladi)

## 📦 Loyihani ishga tushirish:
```bash
# Loyiha papkasida:
npm run dev
```

Brauzerda `http://localhost:5173` manzilini oching.
